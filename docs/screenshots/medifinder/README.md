# MediFinder 화면 캡처

공공데이터포털 **활용사례 등록·운영계정 신청**에 첨부하는 화면이다.
어느 API 신청에 무엇을 붙일지는 [`../../../backend/docs/krdata-operation-account.md`](../../../backend/docs/krdata-operation-account.md) 에 적혀 있다.

파일명 번호는 **신청서에 붙이는 순서**다. 화면이 바뀌어 다시 찍을 때도 번호와 이름은 유지한다 —
신청 문안이 파일명으로 화면을 가리키고 있어서다.

| 파일                       | 화면                    | 무엇이 보이나                                                          |
| -------------------------- | ----------------------- | ---------------------------------------------------------------------- |
| `01-home.png`              | 홈                      | 검색창, 응급실·달빛어린이병원·상급종합병원 추천 섹션                    |
| `02-ai-search.png`         | AI 검색                 | 자연어 질문을 진료과·평가등급 조건으로 변환한 결과                      |
| `03-ai-search-result.png`  | AI 검색 — 결과          | 변환된 조건과 병원 미리보기, `이 조건으로 검색` 연결                    |
| `04-search-filters.png`    | 검색 조건               | 시도·시군구, 진료과목, 등급, 전문의, 전문분야, 우수 병원 필터           |
| `05-search-list.png`       | 검색 결과 (목록)        | 가까운 순 정렬, 거리 배지, 병원명·주소·전화번호                         |
| `06-search-map.png`        | 검색 결과 (지도)        | 같은 결과를 좌표로 찍은 지도 마커                                       |
| `07-hospital-detail.png`   | 병원 상세               | 요일별 진료시간, 진료과목, 의료진 수, 심평원 병원평가 등급              |
| `08-hospital-nearby.png`   | 병원 상세 — 위치        | 근처의 비슷한 병원 (반경 1km · 진료과목 겹침 순)                        |

**AI 검색을 앞에 둔 것은 의도한 순서다.** 심사자가 첨부를 위에서부터 넘겨보므로,
가장 눈에 띄는 화면이 먼저 와야 한다. 홈 다음이 AI 검색이고 그 뒤가 일반 검색·상세다.

`02` 와 `03` 은 같은 대화를 찍은 것이다. `02` 는 패널 전체(헤더 포함), `03` 은 결과 부분이다.
한 장만 붙일 자리에는 `02` 를 쓴다.

## 다시 찍을 때

- 화면 폭은 PC 기준으로 찍는다. 필터가 한 화면에 다 보여야 심사에서 기능을 확인할 수 있다.
- 개인정보가 찍히지 않게 한다. 로그인 상태나 위치 좌표가 주소창에 남지 않는지 본다.
- `03` 의 토큰 사용량 표시처럼 **운영 내부 수치는 가려도 된다.** 기능 확인에 필요한 부분이 아니다.
