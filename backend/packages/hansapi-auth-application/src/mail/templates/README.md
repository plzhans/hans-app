# 메일 템플릿

회원가입·인증 관련 발송 메일의 HTML 양식을 둔다. **이 폴더의 `.html` 이 소스다** —
브라우저로 직접 열어 렌더를 확인하고, Litmus / Email on Acid 에 붙여 클라이언트별 렌더를 본다.

메일러(SMTP 연동, 추후)는 이 HTML 을 읽어 `{{placeholder}}` 를 치환한 뒤 발송한다.

## 파일 규칙

- 이름: `<용도>.<locale>.html` — 예: `email-verification.ko.html`
  - locale 은 **백엔드 짧은 코드**(`ko`, `en`, `ja`, `zh`)를 쓴다. 프론트의 BCP-47(`en-us` 등)이 아니다.
- 지금은 `ko` 만 있다. 다른 언어는 같은 플레이스홀더로 `*.en.html` 등을 추가하면 된다.

## 템플릿 목록

| 파일                         | 용도                 | 방식           |
| ---------------------------- | -------------------- | -------------- |
| `email-verification.ko.html` | 회원가입 이메일 인증 | 인증 코드(OTP) |
| `password-reset.ko.html`     | 비밀번호 재설정      | 인증 코드(OTP) |

이메일 인증과 비밀번호 재설정은 **코드를 메일로 보내는 방식**이다 — 링크를 열게 하지 않고,
사용자가 화면에서 코드를 입력한다. 두 파일의 코드 박스(.code-box) 마크업은 동일하니 한쪽을
고치면 다른 쪽도 맞춰 고칠 것.

## 플레이스홀더 계약

메일러는 아래 키를 채워야 한다. 값은 이미 이스케이프된 상태로 넣는다
(사용자 입력인 `userNameGreeting` 은 HTML 이스케이프 필수 — 아래 주의 참고).

### 공통

| 플레이스홀더           | 의미                                      | 예시                             |
| ---------------------- | ----------------------------------------- | -------------------------------- |
| `{{appName}}`          | 서비스 표시명                             | `HansAPI`                        |
| `{{appUrl}}`           | 서비스 홈 URL (로고 링크)                 | `https://hansapi.co.kr`          |
| `{{userNameGreeting}}` | 인사말 뒤 이름 조각. **없으면 빈 문자열** | ` 홍길동 님` / `` (앞 공백 포함) |
| `{{supportEmail}}`     | 문의 메일 주소                            | `support@hansapi.co.kr`          |
| `{{year}}`             | 푸터 저작권 연도                          | `2026`                           |

### 코드 메일 (`email-verification`, `password-reset`)

| 플레이스홀더         | 의미               | 예시     |
| -------------------- | ------------------ | -------- |
| `{{code}}`           | 인증 코드(OTP)     | `846210` |
| `{{expiresMinutes}}` | 코드 만료 시간(분) | `10`     |

### 코드(OTP)와 만료

인증 토큰은 [`AuthService.requestEmailVerify`](../../auth.service.ts) / `requestPasswordReset` 가
발급한다. 코드 방식으로 가려면 이 발급부를 **짧은 숫자 코드 + 짧은 TTL**(예: 6자리 / 10분)로
맞춰야 한다 — 현재 기본값(이메일 인증 24h, 비번 재설정 1h)은 링크 기준이라 코드에는 길다.

- `{{expiresMinutes}}` 는 실제 코드 TTL 과 반드시 일치시킬 것. 화면 안내와 서버 만료가 어긋나면
  "코드가 유효하다는데 안 된다"는 혼란이 생긴다.
- 코드는 숫자 6자리를 권장(입력·읽기 쉬움). 자릿수를 바꾸면 `.code-box` 의 `letter-spacing`/
  `font-size` 를 눈으로 확인할 것(모바일은 `.sm-code` 로 축소된다).

### 주의

- `{{userNameGreeting}}` 은 사용자 입력에서 나온다. 치환 전 **반드시 HTML 이스케이프**할 것
  (`<`, `>`, `&`, `"` → 엔티티). 나머지 값은 우리가 통제하는 값이지만 습관적으로 이스케이프해도 좋다.
- 이스케이프하지 않은 원본 문자열을 넣으면 메일 클라이언트에서 마크업이 깨지거나 주입에 노출된다.

## 텍스트(plain) 대체본

배달률을 위해 발송은 `multipart/alternative` 로 HTML + 플레인텍스트를 함께 보내는 것을 권장한다.
플레인텍스트 본문은 메일러가 생성한다(별도 `.txt` 템플릿을 두거나, 최소한 인사말 + `code` +
만료 안내를 담은 짧은 텍스트). 스팸 필터는 텍스트 파트가 없는 메일을 불리하게 본다.

## 번들링 메모 (메일러 붙일 때 결정)

이 레포 빌드는 `tsc` + `pnpm deploy`(`"files": ["dist"]`)라 **`.ts` 만 dist 에 담기고 `.html`
은 복사되지 않는다.** 메일러가 런타임에 이 파일을 `readFileSync` 로 읽으려면 둘 중 하나가 필요하다:

1. **인라인(권장):** 빌드 시 이 HTML 을 문자열로 임포트하도록 로더/코드젠을 두거나,
   `email-verification.ko.ts`(HTML 을 export 하는 모듈)로 함께 관리한다. fs 접근이 없어 번들에
   안전하다.
2. **dist 복사:** 빌드 스크립트에 이 폴더를 `dist/mail/templates/` 로 복사하는 단계를 추가하고,
   런타임에 `__dirname` 기준으로 읽는다. 단계가 빠지면 배포 후에만 깨지므로 검증을 붙일 것.

지금은 템플릿 저작이 목적이라 소스는 `.html` 로 둔다. 실제 발송 코드를 붙이는 시점에 위 중 하나를 고른다.
